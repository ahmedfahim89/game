Checks

Not part of the shipped game — tools/ is local only. This page loads the same assets/js/ files the game does, so anything that passes here passes for the same reasons it passes in play.

Validate the script

The buildless substitute for a compiler. Every authored effect, gate and flag is checked against the lists in lib/state.js, which is what catches the failure mode this project cannot otherwise see: a mistyped stat name does nothing at all in the game and says nothing about it. Run this after every content edit.

Simulate for balance

Plays the whole script headlessly under fixed strategies. This is how the game's four claims get checked against its own arithmetic rather than against intention — if the always-grind column stops ending badly, the game has stopped meaning what it says.
